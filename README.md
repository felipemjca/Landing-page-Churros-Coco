# Churros Coco — Landing Page

Landing page desarrollada para **Churros Coco**, una churrería artesanal con locales en Gualeguaychú y Concepción del Uruguay, Entre Ríos, Argentina.

## Descripción

Este proyecto consiste en el desarrollo de una página web destinada a mejorar la presencia digital del negocio, presentar sus productos y facilitar la comunicación con los clientes.

La aplicación está desarrollada con tecnologías web nativas y cuenta con una interfaz diseñada para ofrecer una navegación clara, accesible y adaptable a diferentes dispositivos.

## Funcionalidades

* Presentación de la marca y sus productos.
* Menú con categorías de churros, variedades y precios.
* Sección informativa sobre la producción artesanal y los productos.
* Galería de imágenes.
* Información de los locales, direcciones y horarios.
* Mapas y enlaces a Google Maps para obtener indicaciones.
* Acceso directo a WhatsApp para realizar pedidos.
* Enlaces a teléfonos de contacto e Instagram.
* Navegación adaptable a dispositivos móviles.
* Animaciones de entrada de las secciones durante el desplazamiento.
* Metadatos SEO para mejorar la presentación en buscadores.
* Metadatos Open Graph para personalizar la vista previa al compartir enlaces.
* Consideraciones de accesibilidad, navegación por teclado y reducción de movimiento.

## Tecnologías utilizadas

* **HTML5:** estructura y contenido de la página.
* **CSS3:** estilos, diseño responsive, componentes visuales y animaciones.
* **JavaScript:** interacciones de navegación, revelado de secciones y actualización automática del año del pie de página.
* **Google Fonts:** tipografías Poppins y Dancing Script.
* **Google Maps:** ubicación de los locales e indicaciones para llegar.
* **WhatsApp:** enlaces directos para facilitar la realización de pedidos.

## Requisitos

* Navegador web actualizado.
* Conexión a internet para cargar las tipografías externas y acceder a los servicios integrados.

No requiere la instalación de dependencias ni un entorno de ejecución adicional.

## Instalación

Cloná el repositorio:

```bash
git clone https://github.com/felipemjca/Landing-page-Churros-Coco.git
```

Ingresá a la carpeta del proyecto:

```bash
cd Landing-page-Churros-Coco
```

## Ejecución

Para visualizar la página, abrí el archivo `index.html` directamente en un navegador web.

No es necesario ejecutar comandos de instalación ni iniciar un servidor de desarrollo para la versión actual.

## Estructura del proyecto

```text
Landing-page-Churros-Coco/
├── img/
├── index.html
├── estilos.css
├── script.js
└── .gitignore
```

* `index.html`: estructura, contenido y secciones de la landing page.
* `estilos.css`: diseño visual, distribución de componentes, adaptación a pantallas y animaciones.
* `script.js`: funcionalidades interactivas de la interfaz.
* `img/`: directorio destinado a los recursos gráficos del proyecto.
* `.gitignore`: configuración de archivos y directorios excluidos del seguimiento de Git.

## Diseño y experiencia de usuario

La interfaz utiliza una identidad visual basada en tonos amarillos y crema, acompañados de elementos gráficos que refuerzan la identidad de la marca.

Se priorizan la legibilidad, la navegación intuitiva y el acceso rápido al menú, la ubicación de los locales y los canales de contacto.

El diseño contempla distintos tamaños de pantalla y preferencias de accesibilidad, como la reducción de movimiento para usuarios que la tengan habilitada en su sistema.
